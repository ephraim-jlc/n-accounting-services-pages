Overview

Service Page Wireframes

This is a set of eight low-fidelity (black & white) wireframes for N-Accounting's core service pages. They're built to communicate layout, content hierarchy and section intent before any visual design or brand styling is applied. Each section carries a small annotation tag (top-right) restating its layout purpose, and image areas are shown as labelled placeholders.

The pages are a deliberate matched set: they share the same grid, components, navigation and footer, so the eventual build is consistent and the templates are reusable. Summaries of each page and the shared design blocks are below.

Consistent design blocks

Shared components across all pages

Every page is assembled from the same library of blocks. This keeps the set coherent and means the build can be templated. The reusable components are:

Header

Navigation bar

Logo placeholder + main nav (Home, About Us, Case Studies, Articles, Client Area, Free Stuff, Contact) + "Contact us" button. Matched to the live N-Accounting site.

Hero

Two-column hero + trust strip

H1, value-led intro, primary + secondary CTA on the left; image placeholder on the right. A four-point trust strip sits beneath.

Intro

Full-width intro

Short heading and 2–3 advisory paragraphs introducing the service in plain English.

Explainer

Two-column + support card

Explanatory copy paired with a bordered "helps with" checklist card. Used on every page to define the service.

Services

Card grid

Scannable 2-col (or 3-col) cards with icon placeholders describing each part of the service.

Feature

Feature panel

Bordered white inset used for the strongest commercial/advisory section on a page (tax planning, credibility, advisory insight).

Process

Five-step process

Numbered horizontal timeline on desktop, stacking on mobile. Identical pattern on every page.

Why choose

Intro + benefit cards

Trust-led intro with team image placeholder, plus a row of five short benefit cards.

Audience

Checklist grid

Two-column "who this is for" list so visitors can self-identify.

Conversion

Full-width CTA band

Contrasting band with heading, reassurance line, primary button and a supporting contact line.

Related

Related services cards

Four internal-link cards for cross-linking between service pages.

FAQ

Accordion

Five Q&A items (first open, rest collapsed) indicating accordion behaviour. FAQ schema to be added at build.

Footer

CTA strip + footer

A short repeat-CTA strip, then the dark footer with services, about and contact columns.

Wireframe conventions

How to read these wireframes

Greyscale is intentional — the wireframes communicate structure and content, not brand styling. The visual language is consistent throughout:

Crossed box = image placeholder
Light shade = alternating section
Mid fill = icon / chart placeholder
Dark = primary button / footer
  • The page meta (URL, title, description) sits in the dark strip at the very top of each wireframe.
  • Mock visuals (dashboards, calendars, payslips, flows) are greyscale placeholders to show intent, not final designs.
  • Two open points for sign-off: the footer services order, and whether the five-card "why choose" rows should drop to a 3+2 layout (they run tight on desktop).
  • Next stage would be a single high-fidelity page in N-Accounting's brand palette to lock the look before rolling out across all eight.
